# py-doc-tools

`py-doc-tools` fournit des outils configurables pour générer et maintenir une documentation MkDocs pour des projets Python.

## Outils couverts

- génération de TODO/FIXME ;
- diagnostics Ruff ;
- diagnostics MkDocs/Griffe ;
- injection optionnelle de tags générés dans les sources ;
- orchestration de pipeline documentaire.
